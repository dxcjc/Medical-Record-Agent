# 产品经理任务：需求调研

## 背景
病历识别系统当前识别率约62-79%，需要从多个维度分析问题并提出优化方向。

## 数据集结构
8个测试方向，45个样本：
1. 不同癌种解读匹配（10个）- 测试癌种识别准确性
2. 不同类型病理报告（10个）- 测试报告格式兼容性
3. 不同类型图片识别（7个）- 测试图片质量容错
4. 药厂测试（3个）- 测试药厂申请单识别
5. 资料多样本测试（5个）- 测试多文件合并识别
6. 基因检测（3个）- 测试基因检测报告识别
7. 手术分期（4个）- 测试分期信息提取
8. 多部位乳腺癌（3个）- 测试多部位/多癌种识别

## 任务要求
1. 分析每个测试方向的业务场景和用户需求
2. 梳理每个方向的核心验收标准（什么算识别正确）
3. 调研行业OCR识别最佳实践（不限于知识库方案）
4. 从用户体验角度提出优化建议
5. 输出需求分析报告

## 输出
- 需求分析报告（docs/requirement-analysis.md）
- 每个测试方向的验收标准
- 优化方向建议（多个方案，不限定）
