> 本模板供 `scripts/evaluate.py` 生成报告后人工审阅参考，也可用于手动填写评估结果。

---

## 1. 总体指标

| 指标 | 值 | 说明 |
|------|-----|------|
| **字段召回率** | ___% | 有值字段中被正确识别的比例（不漏识别） |
| **字段精确率** | ___% | 识别结果中正确的比例（不误识别） |
| **字段 F1** | ___% | 召回率和精确率的调和平均 |
| **样本完全正确率** | ___% | 所有字段均正确的样本占比 |
| 总样本数 | ___ | 已排除 REF 参考图片 |
| 完成样本数 | ___ | API 返回 completed 状态的样本 |
| 失败样本数 | ___ | API 返回 failed/error 或超时的样本 |
| 评估耗时 | ___s | 从开始到结束的总耗时 |

### 计算公式

```
字段召回率 = 正确识别字段数 / 期望有值字段数 × 100%
字段精确率 = 正确识别字段数 / 实际识别字段数 × 100%
字段 F1    = 2 × (精确率 × 召回率) / (精确率 + 召回率)
样本完全正确率 = 全字段匹配样本数 / 完成样本数 × 100%
```
