## 三、优化措施

### 3.1 interpretationMatch 规则强化

将所有 interpretationMatch 映射规则从"【重要规则】"升级为"【绝对规则】"，并添加更多具体错误示例：

| 规则 | 修改内容 |
|------|----------|
| 肺癌映射 | 添加3个错误示例，扩展关键词覆盖 |
| 胃癌映射 | 添加2个错误示例，扩展关键词覆盖 |
| 肾癌映射 | 添加2个错误示例，扩展关键词覆盖 |
| 软组织肉瘤映射 | 添加2个错误示例，扩展关键词覆盖 |
| 淋巴瘤映射 | 添加2个错误示例，扩展关键词覆盖 |
| 多癌取原发癌 | 保持原规则 |

### 3.2 cancerTag 规则强化

新增以下情况为单癌（不是多癌）的规则：
- 癌前病变（低级别上皮内瘤变、高级别上皮内瘤变、异型增生）不计入独立原发癌
- 食管鳞状细胞癌伴其他部位低级别上皮内瘤变→单癌
- 食管鳞状细胞癌伴食管其他部位基底细胞增生→单癌
- 同一器官的多处病灶→单癌

添加3个具体错误示例。

### 3.3 cancerCategory 路径标准化

新增"结直肠癌cancerCategory标准路径"规则：
- 直肠腺癌→'肠道/结直肠腺癌/直肠腺癌'
- 结肠腺癌→'肠道/结直肠腺癌/结肠腺癌'
- 右半结肠腺癌→'肠道/结直肠腺癌/结肠腺癌'
- 结肠粘液腺癌→'肠道/结直肠腺癌/结肠粘液腺癌'

强化"恶性肿瘤cancerCategory映射规则"：
- 修正胃恶性肿瘤路径为'胃/胃腺癌'
- 修正肺恶性肿瘤路径为'肺/非小细胞肺癌'

### 3.4 pathologicalDiagnosis 提取规则强化

新增以下提取规则：
- 从'临床诊断'、'诊断'、'术前诊断'、'术后诊断'等栏目中提取病理类型
- 从申请单上的诊断字段提取
- 从基因检测报告上的诊断字段提取

添加3个具体错误示例。

### 3.5 sampleType 规则强化

新增以下判断规则：
- 手写申请单中明确标注的取材部位应优先使用
- 添加4个具体错误示例
