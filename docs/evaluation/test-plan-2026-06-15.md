## 评估维度

### Layer 1: OCR 可读性

| 评估项 | 说明 |
|---|---|
| 文本识别质量 | 图片中的打印体和手写体能否被正确识别 |
| 文本顺序 | OCR 输出文本顺序与实际阅读顺序是否一致 |
| OCR 质量告警 | 系统是否能正确标记模糊、倾斜、手写等质量问题 |

### Layer 2: 核心字段抽取

| 字段 | 说明 |
|---|---|
| 临床诊断 | 主要诊断原文 |
| 肿瘤类型 | 如肺腺癌、胃腺癌、乳腺癌、胶质瘤 |
| 原发部位 | 肺、胃、乳腺、结直肠等 |
| 样本类型 | 组织、血液、胸水、石蜡切片等 |
| 分期 | TNM 分期或总体分期 |
| 日期 | 报告日期、诊断日期等 |

### Layer 3: 复杂诊断推理

| 评估项 | 说明 |
|---|---|
| 原发/转移判断 | 能否区分原发灶和转移灶 |
| 多部位诊断 | 多部位病灶能否正确列出 |
| 原发灶未明 | 未明确原发灶时能否正确标记 |
| 诊断确定性 | 确诊/疑似/排除的判断是否准确 |

### Layer 4: 多资料聚合

| 评估项 | 说明 |
|---|---|
| 多图合并 | 多张图片的 OCR 文本能否正确合并 |
| 信息归并 | 不同页/图片的信息能否正确聚合 |
| 冲突处理 | 信息冲突时能否正确处理或标记 |

### Layer 5: 禁止幻觉/需审核

| 评估项 | 说明 |
|---|---|
| 未提及字段不输出 | 文档中未提及的字段不应被臆造输出 |
| 不完整分期不补造 | 只有 T 分期时不应补造 N/M 分期 |
| 需审核标记 | 不确定的信息应标记需人工审核 |

## 测试指标定义

### 字段级指标

| 指标 | 定义 |
|---|---|
| 精确率 (Precision) | 预测正确的正例 / 所有预测为正例的样本 |
| 召回率 (Recall) | 预测正确的正例 / 所有实际为正例的样本 |
| F1 分数 | 2 × (精确率 × 召回率) / (精确率 + 召回率) |

### 样本级指标

| 指标 | 定义 |
|---|---|
| 完全正确率 | 所有字段都正确的样本数 / 总样本数 |
| 需审核率 | 标记需审核的样本数 / 总样本数 |
| 错误率 | 至少有一个字段错误的样本数 / 总样本数 |

### 病例级指标

| 指标 | 定义 |
|---|---|
| 多图聚合准确率 | 多图任务中信息正确聚合的病例数 / 多图总病例数 |

## Ground Truth 标注规范

### 字段标注原则

1. **优先原文**：优先使用文档中出现的原文
2. **归一化标准**：日期、分期等字段使用统一归一化格式
3. **标记不确定**：不确定的字段标记 `expectedNeedsReview: true`
4. **不臆造**：文档中未提及的字段留空，不臆造

### 各字段标注细则

#### 文档与病例概览

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `documentTypes` | 列出所有识别到的文档类型 | 包含主要类型即可 |
| `patientName` | 脱敏后的患者姓名或样本 ID | 与样本匹配即可 |
| `sourceOrganization` | 医院、检测机构名称 | 关键词匹配 |
| `reportDate` | ISO 格式日期 (YYYY-MM-DD) | 日期正确或正确标记缺失 |
| `diagnosisDate` | ISO 格式日期，无明确日期不填 | 不臆造即正确 |

#### 核心诊断

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `clinicalDiagnosis` | 临床诊断原文 | 与原文一致 |
| `pathologicalDiagnosis` | 病理诊断原文 | 与原文一致 |
| `primaryTumorType` | 如"肺腺癌"、"胃腺癌" | 肿瘤类型正确 |
| `primarySite` | 原发部位 | 部位正确 |
| `primarySiteStatus` | 枚举：`confirmed`/`unknownPrimary`/`suspected`/`notMentioned` | 状态判断正确 |
| `diagnosisCertainty` | 枚举：`confirmed`/`suspected`/`excluded`/`uncertain` | 确定性判断正确 |

#### 多部位与转移

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `involvedSites` | 累及部位列表 | 主要部位正确 |
| `metastasisStatus` | 枚举：`present`/`absent`/`suspected`/`notMentioned` | 状态判断正确 |
| `metastasisSites` | 转移部位列表 | 主要转移部位正确 |
| `multiPrimaryOrMultiSiteNote` | 复杂诊断摘要 | 摘要合理 |

#### 分期信息

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `tumorStage` | 分期原文如"IV期"、"T2N1M0" | 与原文一致 |
| `tnmStage` | 完整 TNM 表达式 | TNM 正确或正确标记缺失 |
| `tStage` | T 分期，只出现 T 时保留 | 不臆造 N/M 即正确 |
| `nStage` | N 分期，只出现 N 时保留 | 不臆造 T/M 即正确 |
| `mStage` | M 分期 | M 分期正确 |
| `pathologicalStage` | 病理分期 | 与原文一致 |
| `stageEvidenceCompleteness` | 枚举：`complete`/`partial`/`absent`/`unclear` | 完整性判断正确 |

#### 样本与检测

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `sampleType` | 样本类型列表 | 主要类型正确 |
| `sampleSite` | 取样部位 | 部位正确 |
| `pathologyNo` | 病理号原文 | 与原文一致 |
| `sampleNo` | 样本编号原文 | 与原文一致 |
| `geneTestItems` | 基因检测项目列表 | 主要项目正确 |
| `geneMutationSummary` | 基因突变摘要 | 摘要合理 |

#### 治疗相关病史

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `surgeryHistory` | 手术史描述 | 与原文一致 |
| `treatmentHistory` | 总体治疗史描述 | 与原文一致 |
| `medicationHistory` | 药物列表 | 主要药物正确 |
| `radiotherapyHistory` | 放疗史描述 | 与原文一致 |
| `chemotherapyHistory` | 化疗史描述 | 与原文一致 |
| `targetedTherapyHistory` | 靶向治疗史描述 | 与原文一致 |
| `immunotherapyHistory` | 免疫治疗史描述 | 与原文一致 |

#### 评估辅助字段

| 字段 | 标注规范 | 判定正确 |
|---|---|---|
| `ocrQualityIssue` | 枚举：`none`/`blurry`/`skewed`/`handwritten`/`multipageOrderRisk`/`unreadable`/`unclear` | 质量问题判断正确 |
| `needsManualReviewReason` | 需审核原因列表 | 原因合理 |
| `finalCaseSummary` | 病例摘要 | 摘要合理 |

### 什么算对？

- 文本字段：与原文一致或归一化后一致
- 列表字段：包含主要项，顺序无关
- 枚举字段：与标注枚举值一致
- 缺失字段：文档中未提及，留空即正确
- 需审核：标注 `expectedNeedsReview: true`，预测也标记即正确

### 什么算错？

- 文本字段：与原文不符
- 枚举字段：枚举值错误
- 臆造字段：文档中未提及但有输出
- 补造分期：只有 T 分期但补造了 N/M

### 什么情况标 needsReview？

- OCR 质量差，无法确定
- 文档描述模糊
- 信息冲突
- 手写体识别不确定
- 分期证据不完整

## 测试执行流程

### 1. 准备阶段

1. 确认测试集文件完整性
2. 导入或创建 `comprehensive-tumor-evaluation` schema
3. 确保系统支持多文件合并任务

### 2. 上传阶段

1. 按样本分组上传图片
2. 多图样本选择"合并为一个任务"
3. 单图样本分别创建任务
4. 选择 `comprehensive-tumor-evaluation` schema

### 3. 识别阶段

1. 系统执行 OCR 和结构化抽取
2. 记录每个任务的执行时间
3. 检查是否有失败任务

### 4. 人工标注阶段

1. 对每个样本进行人工标注 ground truth
2. 标记每个字段的 `expectedNeedsReview`
3. 记录标注过程中的问题

### 5. 评估阶段

1. 使用 `evaluationRunner` 执行批量评估
2. 生成字段级、样本级、病例级指标
3. 生成错误分析报告

### 6. 报告阶段

1. 汇总各分组的表现
2. 分析主要错误类型
3. 提出改进建议

## 注意事项

### 文件名脱敏

- 标注中不应包含真实患者姓名
- 使用样本 ID 或脱敏姓名
- 文件名中如包含敏感信息，在 manifest 中使用相对路径

### 多图样本定义

- 同一病例的多张图片应合并为一个任务
- 期望截图不应作为输入，仅用于人工对照
- 多图顺序按文件名排序或上传顺序

### 期望截图使用方式

- 期望截图用于人工参考，不参与自动评估
- 评估时对比预测结果与期望截图中的标注
- 期望截图中如有明确标注，可作为 ground truth 参考

### 评价分级建议

- 优秀：字段级准确率 > 90%，完全正确率 > 80%
- 良好：字段级准确率 80-90%，完全正确率 60-80%
- 合格：字段级准确率 70-80%，完全正确率 40-60%
- 需改进：字段级准确率 < 70%，完全正确率 < 40%
