## 🔍 发现的问题

### 问题1: cancerCategory路径格式不一致 ⚠️

**问题描述**: 知识库中存在两套不同的路径模板，导致Agent输出不一致。

**路径模板A（正确）** — 来自 `cancer_alias` 和 `cancer_tag`:
```
肺/非小细胞肺癌/肺腺癌
乳腺/乳腺癌/浸润性导管癌
肠道/结直肠腺癌/直肠腺癌
胃/胃腺癌
淋巴/淋巴瘤/非霍奇金淋巴瘤/成熟B细胞肿瘤/弥漫性大B细胞
```

**路径模板B（错误）** — 来自 `field_description`:
```
呼吸系统/肺/腺癌
消化系统/胃/腺癌
生殖系统/乳腺/浸润性导管癌
泌尿系统/肾/肾细胞癌
血液系统/淋巴瘤/弥漫大B细胞淋巴瘤
```

**影响**:
- TC007: baseline期望 `食管/食管鳞状细胞癌`，Agent可能输出 `消化系统/食管/鳞状细胞癌`
- TC010: baseline期望 `胃/胃腺癌`，Agent可能输出 `消化系统/胃/腺癌`

**建议**: 删除路径模板B，统一使用器官开头的格式。

### 问题2: pathologicalDiagnosis输出规则冲突 ⚠️

**问题描述**: 知识库中有两条规则相互冲突。

**规则A** — `field_description|pathologicalDiagnosis必须输出简短标准化诊断`:
```
只输出核心诊断结论，通常是「部位+诊断」的简短格式
不要包含免疫组化细节、脉管侵犯、切缘状态等
示例：报告写「（右肺纤支镜活检，EBUS）符合中分化腺癌细胞；脉管内癌栓(-)」→ 只输出「肺腺癌」
```

**规则B** — baseline期望值:
```
TC005: （右肾）符合缺陷型肾细胞癌
TC013: （右肺上叶）浸润性非黏液性腺癌
TC016: （左乳）浸润性导管癌，伴原位癌，原位癌成分示囊内乳头状癌、原位型实性乳头状癌和导管原位癌
```

**影响**:
- TC016: baseline期望完整描述，Agent按规则A输出简化版
- TC009: baseline期望完整描述，Agent按规则A输出简化版

**建议**: 修改规则A，改为"输出报告中的核心病理结论，保留部位和主要诊断类型，但不包含免疫组化、脉管侵犯等细节"。

### 问题3: cancerTag多癌判断规则不清晰 ⚠️

**问题描述**: 多癌判断规则中，"同器官同类型的多灶癌仍算单癌"的定义不清晰。

**当前规则**:
```
判断单癌/多癌的标准：看病理报告中有几个独立的癌症诊断。
同器官同类型的多灶癌仍算单癌。
不同器官或不同病理类型的算多癌。
```

**实际案例**:
- TC043: 结肠+小肠 → baseline期望 "结肠癌,小肠癌"，Agent输出 "单癌"
- TC044: 乳腺导管原位癌+浸润性癌 → baseline期望 "乳腺导管原位癌,乳腺浸润性癌"，Agent输出 "单癌"
- TC045: 肺小细胞癌+肺腺癌 → baseline期望 "肺小细胞癌,肺腺癌"，Agent输出 "单癌"

**问题**: 结肠和小肠是不同器官，应该算多癌。但Agent可能认为都是"肠道"，所以算单癌。

**建议**: 明确定义"器官"的粒度，例如"结肠"和"小肠"算不同器官。

---

### 问题4: interpretation_match规则过于简化 ⚠️

**问题描述**: interpretation_match规则将复杂的病理诊断简化为单一癌种名称。

**当前规则**:
```
乳腺浸润性导管癌、乳腺导管原位癌、乳腺浸润性癌均解读匹配为'乳腺癌'。
```

**影响**:
- TC014: baseline期望 `乳腺/乳腺浸润性导管癌`，Agent输出 `乳腺/乳腺癌`
- TC016: baseline期望 `乳腺/乳腺浸润性导管癌, 乳腺/乳腺导管原位癌`，Agent输出 `乳腺/乳腺癌`

**建议**: interpretation_match规则应该保留亚型信息，而不是简化为大类。
