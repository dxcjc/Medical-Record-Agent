## 问题 1：Provider 卡片样式错乱 ✅

### 问题描述
- **文件**：`medical-ui/src/pages/ProviderPage.tsx`
- **症状**：Endpoint URL 等长文本内容超出卡片边界，导致布局破坏
- **影响范围**：Provider 管理页面的卡片展示

### 根因分析
第 322-340 行的 `Descriptions` 组件中，Key 和 Endpoint 字段未设置文本截断或自适应处理，导致长字符串溢出。

### 修复方案
在 `ProviderPage.tsx` 第 325-339 行应用以下改进：

```tsx
// 修复前
{ label: 'Key', value: p.key },
...(showEndpoint ? [{ label: 'Endpoint', value: endpoint }] : []),

// 修复后
{ label: 'Key', value: <Text style={{ wordBreak: 'break-all' }}>{p.key}</Text> },
...(showEndpoint ? [{
  label: 'Endpoint',
  value: (
    <Text
      style={{
        wordBreak: 'break-all',
        fontSize: 12,
        display: 'block',
        maxWidth: '100%',
      }}
      title={endpoint}
    >
      {endpoint}
    </Text>
  )
}] : []),
```

**关键改进**：
- 使用 `wordBreak: 'break-all'` 强制长单词换行
- 添加 `title` 属性显示完整 URL（鼠标悬停）
- 设置 `maxWidth: '100%'` 确保内容不超出容器

## 问题 3：Schema 识别统计数据缺失 ✅

### 问题描述
- **文件**：`medical-ui/src/components/FieldCard.tsx`
- **症状**：Schema 识别统计区域显示"暂无统计数据"，无引导信息
- **影响范围**：Schema 详情页的字段统计展示

### 根因分析

#### 后端验证（✅ 正常）
1. **API 实现**：`apps/api/src/routes/stats.routes.ts` 第 44-59 行
   - 端点：`GET /stats/fields?schemaKey={key}&limit={n}`
   - 返回格式：`{ stats: FieldStatItem[], total: number }`

2. **数据服务**：`apps/api/src/services/stats.service.ts` 第 71-156 行
   - 从 `RecognitionResult` 聚合字段使用数据
   - 从 `FeedbackSubmission` 统计修正次数
   - 计算置信度均值、需复核数等

#### 前端调用（✅ 正常）
- `SchemaPage.tsx` 第 320 行：`useFieldStats(schemaKey)` 仅在选中 Schema 时传递参数
- 数据流：API → `useFieldStats` hook → `FieldCard` 组件

#### 实际问题
**空状态提示不够友好**，用户不清楚为何没有数据（是 API 错误还是未运行任务）。

### 修复方案
优化 `FieldCard.tsx` 第 368-416 行的空状态提示：

```tsx
// 修复前
{stats ? (
  <div style={{ display: 'grid', ... }}>
    {/* 统计数据 */}
  </div>
) : (
  <Text type="secondary" style={{ fontSize: 12 }}>暂无统计数据</Text>
)}

// 修复后
{stats ? (
  <div style={{ display: 'grid', ... }}>
    {/* 统计数据 */}
  </div>
) : (
  <div style={{
    padding: '12px 0',
    textAlign: 'center',
    background: 'var(--color-fill-1)',
    borderRadius: 4
  }}>
    <Text type="secondary" style={{ fontSize: 12 }}>
      暂无统计数据 - 运行识别任务后将显示此字段的使用情况
    </Text>
  </div>
)}
```

**改进点**：
- 增加背景色和圆角，提升视觉层次
- 明确说明数据来源（"运行识别任务后"）
- 引导用户下一步操作
